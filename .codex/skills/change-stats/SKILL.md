# 变更行数统计

默认数据源为 `git diff HEAD --numstat`，同时包含已暂存与未暂存；用户只问暂存时用 `git diff --cached --numstat` 并标明口径。不改文件，不展开代码 diff。

## 统计口径

- 默认不含未跟踪文件；用户要求包含时另行计数并说明，不能把普通 Git diff 当作新文件总量。
- 默认从代码合计扣除根 `reports/` 与 `.codex/skills/performance-baseline/reports/`；单列被排除的文件与增删行数，不静默丢弃。
- 使用当前系统已有工具聚合，无须依赖 PowerShell。numstat 的前两列为新增/删除数；二进制的 `-` 不强转数字，单列为无法计行的文件。
- 净变化 = 新增 − 删除；总改动行数（churn）= 新增 + 删除。空 diff 为零，不把两者混称。
- 按 Rust 后端、前端组件/feature、应用/API、文案/样式、Scripts/CI、Skills、其他归组；文件保留 numstat 顺序。

## 输出

1. 说明比较基线、是否含未跟踪文件及排除范围。
2. 合计新增、删除、净变化、总改动行数与文件数；并列含报告/不含报告口径。
3. 按目录小计与逐文件 `+ / -` 清单，报告文件标注已扣除。
4. 仅补充实际有用的观察；移动/拆分不自动等于新增功能，行数也不证明行为变化。
